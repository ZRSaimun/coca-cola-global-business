# Coca-Cola: Global Business Strategy

A phone-friendly companion to our BUSI-1763 group mind map. Explore the A1 poster, four module lenses, the group conclusion and the sources behind the analysis.

**Live presentation:** https://zrsaimun.github.io/coca-cola-global-business/

This is a student group project, not an official Coca-Cola publication.

The presentation includes a six-chapter, scroll-controlled value-chain journey with 48 storyboard frames. The chapters cover ingredient preparation, bottle production, filling, packaging and quality, local distribution, and customers. Without JavaScript, or with reduced motion turned on, the same chapters appear as an illustrated list. Journey images are illustrative, not photographs of Coca-Cola facilities.
